# Eczema Detection in paediatric darker skin

## 🩺 Project Summary
Racial underrepresentation in skin datasets lead to sub-optimal performance of models when analyzing darker skin which is a problem especially for paediatric cases. This project seeks to bridge that gap by building a model that is trained with darker skin tones (Fitzpatrick level 3 to 6) with an explainability framework. The dataset used is the PASSION dermatology dataset.

**PASSION (Pigmented Skin Image Collection)** is a project aimed at enabling AI driven teledermatlgy platform.
